## Verification

`cargo xtask ci` runs this suite at Tier 1. The crate opens no device, launches
no process, and performs no privileged operation; it writes files where it is
told to and refuses everything else, so nothing here can reach a host or user
disk (SAFE-001, SAFE-002).

The interlock's tests build a real fixture tree in a temporary directory and
verify against it, rather than against a mocked manifest. A mocked filesystem
would test the interlock's arithmetic while leaving the question it exists to
answer — what happens when a real path resolves somewhere unexpected —
unasked.

## Known gaps carried into later increments

- **No Tier-2 suite exists**, so the interlock has never gated a real destructive
  operation. Every test proves it refuses; none proves what it permits, because
  nothing yet asks it for permission. That arrives with increment 2 and it is the
  most important gap in this package.
- The `a_symlink_is_refused` test is Unix-only. Windows symlink creation needs
  either Developer Mode or elevation, and SAFE-002 keeps the default suite
  unprivileged. The non-symlink path checks still run on Windows.
- Fixtures carry partition tables only; no fixture contains a real file system,
  LVM metadata, LUKS header, or RAID superblock. FS-004 detection has no fixture
  yet, and ADR-C5's verification plan needs several that do not exist.
- No golden-image *integration* test consumes these fixtures yet, because the
  domain types they would be parsed into are blocked at WP-010 increment 3.
