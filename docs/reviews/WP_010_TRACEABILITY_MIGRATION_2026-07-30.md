## Zero-loss check

The generated document is deliberately narrower than the old narrative: it is
an evidence table, not a status report. Status, negative claims, manual checks,
and remaining limitations now live in the work-package document, while
test-to-requirement relationships live beside compiled Rust tests and
cross-language/path relationships live in the typed evidence block.

`cargo xtask traceability` validates the generated output byte-for-byte, test
names against compiled libtest output, paths against Git and WP-010 ownership,
commands against the real xtask parser, and requirement references against
`AGENT_BUILD_SPEC.md`. Semantic adequacy remains a review obligation and is not
misrepresented as mechanically proven.
