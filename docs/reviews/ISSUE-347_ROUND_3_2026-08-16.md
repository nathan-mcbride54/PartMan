## 2. The design, and the two findings that shaped it

**A step whose target is a partition table and whose own destroyed ranges
reach it destroys the table; a destroyed table releases every partition
whose `parent_table` names it.** Nothing else releases.

*Finding 1 — the trigger is the target, and only the target.* The first
draft seeded a "wholly destroyed" set from the target and let it
propagate through the cascade so a table on a destroyed volume would
release too. That is right in principle and it closes the #360 chain
(§4). But at HEAD the chain is unbuildable — #360's row is absent — so
the propagation clauses were **uncovered**, and two mutations on them
survived. Round 2 rejected an uncovered clause outright (L3). The
propagation was cut; the release keys on the target alone; #360's act
adds it with its row and fixture. Recorded with the measurement, so
#360's round does not re-derive it.

*Finding 2 — `f11`/`f12` were spelled on the wrong target.* Both
committed assertions delete `bios_grub` with **the table** as target and
the entry's bytes destroyed. Under target-keyed release that spelling
releases — the closure has no non-authored way to tell one GPT entry
from the header — while the honest spelling (`Wipe` on the partition,
which is what the panel measured as L1 and what the planner emits) is
10/10 `Clear` and reaches only the entry. Both are now asserted side by
side: the honest one as the guard, the table-target one as the priced
limit. This is the "separate the table was destroyed from something
inside the region the body attributes to the table was destroyed" the
panel asked for, drawn on target identity — the only place the closure
can draw it.

## 6. Rejected

Coverage (round 1); intersection (round 2); target identity alone (M4);
CTE released (M2); `canonical_ranges` declaring released extents (moves
the release into every range producer, a new fail-open on an
under-declaring plan step); propagation without its fixture; seeding an
extentless target on the presence of ranges (nothing to see).
